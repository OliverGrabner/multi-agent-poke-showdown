Does talking make LLM teammates win more?

Pokémon Showdown Multi Battles · Gen 9 · Qwen3.8-27B, reasoning effort medium unless stated · built

Two Qwen agents play as teammates, one Pokémon each. We vary how much they may talk before each turn and measure how often their team wins. Every condition plays the same 25 team draws twice with the sides swapped, so the conditions face exactly the same battles.

    Random teams: win rate

    Big model vs smaller models (random teams)

    Qwen3.8-27B (medium reasoning) against smaller Qwen3.5 models, both teams with free talk. The 2B model is about 12 times smaller and does not think (its default); the 9B model is about 3 times smaller and thinks. Same team draws for every run, each played twice with the sides swapped.

    Random teams: numbers per condition (against the max-power bot)

    "Same battles, only one side won": of the battles both this condition and free talk played (same teams, same seed), how many only free talk won and how many only this condition won; p is an exact McNemar test. Output tokens include thinking. Crashed battles (model-server timeouts) are left out.

    Strategy teams (mirror matches)

    Four prebuilt level-50 doubles teams (Trick Room, Tailwind, Rain, Sun), each split so its combo needs both partners: one player has the setter, the other has the Pokémon that need it. Both sides get the same team (a mirror match), so neither side has the better team. 48 battles per run, 12 per team.

    Wins by team are the first side's wins with that team (both sides play it). Crashed battles (model-server timeouts) are left out.

    Read a battle

    Every message and choice, turn by turn. Blue is p1 + p3, Red is p2 + p4; the run name says who is who. An "m" after the number is the same team draw with sides swapped.
